# 手册：搜索缺口

**目的**：买家搜得到词、却搜不到货或不点——要么是标题没写对（能补），要么是真的没这个货（只能报上新机会，
不能瞎编标题）。

## 看哪些工具

- `search_insights`（无结果词、低点击词）。
- `list_products` / `get_product`：确认是不是「有货但标题没写对」。
- `list_my_proposals`（查重）：同一商品是否已有待处理的 `product_copy` 提案。
- `propose_product_copy`（提案）。

## 判断规则

对无结果词（搜索次数 ≥ 3）与低点击词：

> 「无结果」包括两种：一条都没搜到，和只搜到相关度低于下限的「猜你想要」（买家看到的是「没有找到 … 相关的
> 商品，看看这些相近的」）。所以一个无结果词下面，买家其实可能看到过几件不相干的商品——它们不是匹配。

1. 先看店里有没有对应的商品：用词面意思去 `list_products` / `get_product` 找。找到一个**明显匹配**的商品——
   卖的确实是这个东西，只是标题、副标题里没写这几个字（比如买家搜「无线鼠标」，商品叫「M3 蓝牙鼠标」，
   实际支持无线连接却没提「无线」二字）→ 这是标题问题，可以改。
2. 找不到任何匹配商品，或者“匹配”要靠脑补（比如搜「儿童滑板车」，店里只卖成人滑板车，硬说是同一个商品）→
   这是上新机会，不是标题问题，**不要**提 `product_copy`（改了标题也变不出这个商品，而且会话术失真）。
3. 低点击词：点开 `get_product` 看现有标题是否清楚描述了卖点（材质、型号、适用场景），标题含糊、缺买家会
   搜的关键限定词 → 可以改；标题已经写得清楚但就是点击率低（可能是价格、图片问题）→ 不是标题能解决的，写简报。

## 什么时候提案 vs 只写简报

- 有明确匹配商品 + 标题 / 副标题确实缺这几个字 + 这名 AI 员工是全店范围 → `propose_product_copy`；
- 没有匹配商品（上新机会）→ 只在简报「搜索」部分写一句「买家在搜 XX，店里没有对应商品，可能是上新机会」，
  不提案；
- 门店 / 大区范围的 AI 员工遇到该改的标题 → 不要硬提（`role-forbidden`），写进简报交给全店范围的同事；
- 同一商品已有待处理的 `product_copy` 提案 → 跳过。

## 证据怎么写

`evidence` 里写清楚：`search_insights` 的调用参数（`period` / `start_date` / `end_date`）、这个词的搜索次数
（或展现与点击、CTR）、`get_product` 看到的现有 `title` / `subtitle`，以及新标题里加了哪几个字、为什么加，例如：

> search_insights（period=last_7_days）：「无线鼠标」近 7 天搜索 9 次、0 次有结果。get_product(product_id=42)：
> 现有标题「M3 蓝牙鼠标」、副标题「静音办公」，SKU 支持 2.4G 无线接收器，但标题和副标题都没有「无线」二字，
> 买家用这个词搜不到。新标题：「M3 无线蓝牙鼠标」。

新标题 / 副标题自己过一遍广告法违禁词的常识检查（「最」「第一」「国家级」这类词不要出现在建议里），
执行时 Keel 还会再查一遍，但别指望执行端兜底、自己先写干净。

## 上限

- 标题 ≤60 字、副标题 ≤120 字；不改的字段不给（`title` / `subtitle` 传 `null`）；
- 需要全店范围的 AI 员工；
- 同一商品已有待处理提案会被拒（409）；
- 不确定是不是真的匹配，宁可只写简报，不要为了「有产出」硬凑一条改标题的提案。
